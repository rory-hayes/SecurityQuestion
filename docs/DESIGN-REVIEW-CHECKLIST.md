# Design Review Checklist

## Visual consistency
- [ ] Typography scale and spacing are consistent across landing and app pages.
- [ ] Neutral palette and single accent are applied consistently.
- [ ] No placeholder or generative-looking artwork appears in product UI.

## Trust signals
- [ ] Landing page includes evidence-first workflow and explicit approval gating.
- [ ] Security controls are visible above the fold and in FAQ.
- [ ] Review queue surfaces citations and low-confidence warnings clearly.

## Catalyst enforcement
- [ ] All base UI components are imported from `@sqc/ui-catalyst`.
- [ ] UI governance check passes with zero restricted import violations.

## Copy policy
- [ ] No unsupported absolute claims are present.
- [ ] Claims are expressed as targets or measured outcomes.
- [ ] Language frames workflow as analyst-in-the-loop.
